Overview
This project demonstrates a many-to-many relationship between Student and Course entities in a database. In this mapping, a single student can enroll in multiple courses, and a single course can have multiple students enrolled. The relationship is implemented using a join table.

Features
Create and manage Student and Course entities.
Establish and persist many-to-many relationships between students and courses.
Fetch and display students enrolled in a course and courses taken by a student.
